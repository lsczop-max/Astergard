# Weapon Tag Dictionary

Ten słownik definiuje kanoniczne tagi używane przez profile broni.
Tagi są małe, techniczne i nie powinny być dublowane synonimami.

## Forma i konstrukcja

### `blade`

- Znaczenie: broń oparta na krawędzi tnącej.
- Użycie: miecze, szable, topory, halabardy.
- Nie dublować jako: `cutting`, `sharp_edge`.

### `blunt`

- Znaczenie: broń oparta na uderzeniu masą.
- Użycie: młoty, buławy, cepy, kije bojowe.
- Nie dublować jako: `heavy`, `clubbed`.

### `pointed`

- Znaczenie: broń zakończona grotem.
- Użycie: sztylety, włócznie, halabardy.
- Nie dublować jako: `piercing_tip`, `spike`.

### `shafted`

- Znaczenie: broń osadzona na drzewcu lub trzonku.
- Użycie: włócznie, halabardy, kije bojowe.
- Nie dublować jako: `pole`, `staffed`.

### `flexible`

- Znaczenie: broń wykorzystująca giętkość lub ruchome połączenie.
- Użycie: cepy.
- Nie dublować jako: `whippy`, `chainlike`.

### `hooked`

- Znaczenie: broń ma hak, zaczep albo zakrzywione zakończenie.
- Użycie: halabardy.
- Nie dublować jako: `crooked`, `grabby`.

## Zachowanie bojowe

### `agile`

- Znaczenie: broń lekka i szybka w pracy.
- Użycie: miecze, szable, sztylety.
- Nie dublować jako: `fast_weapon`, `swift`.

### `parry_capable`

- Znaczenie: profil wspiera jawne parowanie.
- Użycie: broń, która realnie nadaje się do parowania.
- Nie dublować jako: `defensive`, `parry_ready`.

### `crushing`

- Znaczenie: nacisk na zgniatanie, miażdżenie lub ciężkie uderzenie.
- Użycie: młoty, buławy, cepy, kije bojowe.
- Nie dublować jako: `smashing`, `impact`.

### `armor_breaker`

- Znaczenie: profil pomaga w przełamywaniu ochrony.
- Użycie: ciężkie bronie, które mają sens jako narzędzie przeciw pancerzowi.
- Nie dublować jako: `armor_piercing`, `penetrating`.

### `shield_breaker`

- Znaczenie: profil dobrze radzi sobie z blokiem tarczą.
- Użycie: topory, niektóre halabardy.
- Nie dublować jako: `guard_breaker`.

### `reach`

- Znaczenie: profil zapewnia większą kontrolę dystansu.
- Użycie: włócznie, halabardy, kije bojowe.
- Nie dublować jako: `range`, `long_reach`.

### `close_quarters`

- Znaczenie: profil jest wygodny w bardzo bliskim kontakcie.
- Użycie: sztylety, krótkie bronie.
- Nie dublować jako: `in_melee`, `tight_space`.

### `disarm_capable`

- Znaczenie: profil ułatwia wybijanie lub podbieranie oręża.
- Użycie: halabardy, wybrane bronie zaczepowe.
- Nie dublować jako: `unarm`, `weapon_snatcher`.

### `stun_capable`

- Znaczenie: profil wspiera ogłuszające uderzenie.
- Użycie: młoty, buławy, część ciężkich broni.
- Nie dublować jako: `stunning`, `concussive`.

## Sposób użycia

### `one_handed`

- Znaczenie: broń zajmuje jedną rękę.
- Użycie: profile, które mogą współistnieć z tarczą.
- Nie dublować jako: `single_hand`, `1h`.

### `two_handed`

- Znaczenie: broń wymaga obu rąk.
- Użycie: profile, które wykluczają aktywną tarczę.
- Nie dublować jako: `dual_hand`, `2h`.

### `versatile`

- Znaczenie: profil przygotowany do więcej niż jednego chwytu.
- Użycie: bronie, które później mogą wspierać elastyczny model użycia.
- Nie dublować jako: `flexible_hand`, `hybrid`.

## Zasady utrzymania słownika

- Nie dodawać synonimów tego samego znaczenia.
- Nie używać tagów jako luźnych opisów fabularnych.
- Nie dodawać nowego tagu bez najpierw sprawdzenia, czy istniejący nie pokrywa już tej funkcji.
- Tag powinien coś znaczyć w modelu, a nie tylko ładnie wyglądać w opisie.
