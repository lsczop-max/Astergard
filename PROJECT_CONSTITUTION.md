# Project Constitution

1. Kod domenowy nie zakłada bezpośrednio transportu Telnet ani SQLite.
2. Duże systemy są rozdzielone na pakiety: server, commands, database, world, characters, items, combat, npcs, quests, factions, economy, crafting, magic, weather, admin.
3. Brak pustych fasad: każdy pakiet zawiera działający kod domenowy albo usługowy.
4. Każdy etap musi przejść testy przed uznaniem go za ukończony.
5. Raport pokrycia nie jest deklaracją marketingową; wskazuje status core/full oraz dowody.
6. Zakazane jest dopisywanie TODO jako substytutu implementacji.
